1. `schema_version` を上げず、移行導線もないまま child の空 `ref_planes` の意味を固定しているのは後方互換性違反です。`Component.ref_planes` は省略可能で、空配列でも canonical three でも YAML では省略されます ([component.rs](/home/bacon/engawacad/crates/engawa-format/src/component.rs:141), [ref_plane.rs](/home/bacon/engawacad/crates/engawa-format/src/ref_plane.rs:68))。一方で parse 時に canonical を補完しているのは root だけで ([document.rs](/home/bacon/engawacad/crates/engawa-format/src/document.rs:96))、child の意味は build 時にだけ Option B へ倒されています ([lib.rs](/home/bacon/engawacad/crates/engawa-build/src/lib.rs:573))。しかも `CURRENT_SCHEMA_VERSION` はまだ `1` のまま ([document.rs](/home/bacon/engawacad/crates/engawa-format/src/document.rs:10)) で、MigrationHook は契約しかなく driver 未定です ([015-phase9-design-foundations.md](/home/bacon/engawacad/docs/decisions/015-phase9-design-foundations.md:56))。つまり「親 datum 継承を期待して書かれた既存 child 省略形」を識別も変換もできず、silent semantic break になります。

2. 採用理由のうち「parser-level 不変との整合」と「stdlib 部品の安定化」は migration 根拠として弱いです。parser は child を canonical 化していないので、整合しているのは build 層だけです ([document.rs](/home/bacon/engawacad/crates/engawa-format/src/document.rs:96), [lib.rs](/home/bacon/engawacad/crates/engawa-build/src/lib.rs:573))。また `ComponentRef::StdLib` / `File` は別 Document を `from_path()` で読み直して root を再帰展開しており、参照 subtree は元から独立です ([lib.rs](/home/bacon/engawacad/crates/engawa-build/src/lib.rs:595))。実際に影響を受けるのは inline child だけで、既存 golden の assembly も child に `ref_planes` を書かない形を既定 wire format にしています ([golden_examples.rs](/home/bacon/engawacad/crates/engawa-format/tests/golden_examples.rs:212))。T16/T17 は新挙動を固定するだけで、旧文書の検出・拒否・自動修正を何も担保していません ([refplane_acceptance.rs](/home/bacon/engawacad/crates/engawa-build/tests/refplane_acceptance.rs:374))。

refute 理由: 本 ADR は Option B 自体の設計是非よりも、既存 `.engawa` の意味変更を `schema_version: 1` のまま build 層にだけ滑り込ませている点で、移行容易性と後方互換性の条件を満たしていません。child の `ref_planes` は省略が既定で、空配列と canonical three も同じ wire format に潰れるため、過去文書が「親継承を意図した省略」だったのか「canonical fallback を意図した省略」だったのか識別不能です。しかも MigrationHook の自動適用 driver も未実装で、draft 自身は「追加実装不要」としています。これは壊れる既存文書を検知も救済もせず、実行時 `UnknownRefPlane` か意味変化として放置する宣言に等しいです。少なくとも schema bump、旧 child 省略形の明示 reject、あるいは自動 rewrite 手順のいずれかが ADR 本文に入らない限り承認できません。

verdict: refuted
