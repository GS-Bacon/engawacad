  - **false-reject (Chamfer で新規に到達可能)**: 先行 Chamfer が挿入した派生 Line (`{a}_{b}_chamfer_line`) を対象にする2段目の Chamfer/Fillet は build では成功するが、CRUD gate は元 profile に該当 ID が無いため `SketchElementNotResolved { reason: "sketch_fillet_elem_not_found" }` で拒否する。Fillet 単体ではこの class は発生しない (派生要素が Arc であり、Fillet/Chamfer は共に Line-Line only のため対象外になる)。Chamfer の派生要素が Line であることに由来する新しい乖離である。
  - **false-accept (#296 T13 の Chamfer 版)**: 先行 Chamfer で非隣接化した `(l1, l2)` を対象にする2段目の Chamfer は CRUD gate を通過し、build で `InvalidParameter { kind: "sketch_fillet_elems_not_adjacent" }` として初めて失敗する。「gate は ID/隣接性のみを見る参照解決チェックであって幾何 validator ではない」(`feature_crud.rs:660-663`) という既存設計の帰結。
  gate 側で current profile を段階的に再構築する修正は `simulate_history` が kernel の幾何 op を実行することを意味し (「history gate is a ref-resolution check, not a geometry validator」という既存設計判断の反転)、Fillet/Offset の gate にも同時に波及し、`build_bodies_from_features` の profile replay ロジックを `feature_crud` へ共有抽出する refactor を伴うため、本 Issue では扱わない。
